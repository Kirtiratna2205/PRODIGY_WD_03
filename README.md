🎮 PRODIGY_WD_03

Tic-Tac-Toe Web Application – Prodigy InfoTech Web Development Internship Task 03

📌 Project Overview

This project is an interactive Tic-Tac-Toe web application developed as part of the
Prodigy InfoTech Web Development Internship (Task 03).

The application allows users to play:

👥 Player vs Player

🤖 Player vs AI

It demonstrates strong concepts of JavaScript game logic, DOM manipulation, UI state handling, and a clean, responsive design using HTML, CSS, and JavaScript.

✨ Features

🎮 Player vs Player mode

🤖 Player vs AI mode

🧠 Basic AI logic for automated moves

🏆 Live scoreboard (X wins, O wins, Draws)

🔄 Restart Game & Reset Match options

🏠 Mode selection screen

📱 Fully responsive layout

🎨 Clean UI with smooth interactions

🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling & responsiveness

JavaScript (ES6) – Game logic & interactivity
